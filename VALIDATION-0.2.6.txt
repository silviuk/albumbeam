PhotosBeam 0.2.6 — choose Google Photos through Edge on Android

- Optional Choose in Edge creates the existing Picker session, sends it to the
  paired TV, and limits the selection VIEW intent to the stable Edge package.
- Default selection and desktop flows remain available; the desktop-link dialog
  can also open the existing selection in Edge on this phone.
- Missing/disabled or policy-blocked Edge gives an explicit recovery dialog with
  install, retry, default-app and dismiss actions. No silent default-app fallback.
- HTTPS selection URLs only; diagnostics exclude picker URLs and credentials.
- No new dependencies, manifest permissions, package-visibility queries or settings
  changes. TV playback, pairing storage, signing identity and OAuth stay unchanged.
- The bulk-selection browser extension is not part of this release.

Validation completed:
- Kotlin/Compose and instrumentation source compilation pass locally.
- Existing 65 non-network unit tests pass locally.
- Both app builds, full unit suites, phone/TV lint and both instrumentation APK
  builds pass in CI: https://github.com/silviuk/albumbeam/actions/runs/42407843184
- Original signing certificate, package IDs, PhotosBeam version 0.2.6 (17),
  unchanged dependency classes, preserved existing resource IDs and 16 KiB
  alignment verified for both signed APKs.
- Intent checks compile for Edge package targeting, default package neutrality,
  browser category and rejection of executable/cleartext selection links.

Not run: physical Edge launching/installation, device instrumentation tests or
Google's subsequent redirect/app-opening behavior. The initial launch targets
Edge; that browser can offer to open another app during later navigation.
